## 🌟 Executive Summary

**SubNetCalc Electron v1.1.2** delivers a major capability expansion bringing full parity with the native Swift implementation [SubnetCalc-MacOS](https://github.com/alsyundawy/SubnetCalc-MacOS) (`ThemeManager.swift` and `IPSubnetcalc.swift`), multi-cloud subnet reservation analysis, a draggable floating modal dialog, Windows x64 automated builders, and an enterprise 13-pillar code quality hardening pass:

- 🎨 **25 Developer Theme Families (75 Presets)**: Expands the theme engine from 14 palettes to 25 authentic developer families (75 distinct curated presets) matching `SubnetCalc-MacOS` (Catppuccin, Dracula, Gruvbox, Solarized, Tomorrow, Nord, Tokyo Night, One Dark, Monokai, SynthWave '84, GitHub, Cyberpunk, Rose Pine, Material, Night Owl, Ayu, Horizon, Cobalt2, Palenight, Shades of Purple, Andromeda, LaserWave, Poimandres, Kanagawa, Moonlight). Grouped cleanly via hierarchical `<optgroup>` in the header with instant CSS custom property injection and `localStorage` persistence.
- ☁️ **Multi-Cloud Subnet Reservation Engine**: Algorithmic calculation of usable IP allocations and cloud-reserved addresses across 5 major enterprise profiles:
  - **Standard RFC 1918**: 2 reserved addresses (Network .0 & Broadcast).
  - **AWS VPC**: 5 reserved addresses (Network .0, VPC Router .1, AWS DNS .2, Future Use .3, Broadcast).
  - **Azure VNet**: 5 reserved addresses (Network .0, Default Gateway .1, Azure DNS .2, Azure DNS .3, Broadcast).
  - **Google Cloud Platform (GCP)**: 4 reserved addresses (Network .0, Default Gateway .1, Second-to-last reserved, Broadcast).
  - **Oracle Cloud Infrastructure (OCI)**: 3 reserved addresses (Network .0, Default Gateway .1, Broadcast).
  - Complete minimum prefix boundary enforcement (/28 for AWS, /29 for Azure & GCP, /30 for OCI) and expandable breakdown table detailing every reserved IP and architectural role.
- 🪟 **Draggable Floating About Modal**: The About dialog can now be dragged smoothly across the viewport with mouse or touch input. Includes tactile grab affordances (`cursor: grab / grabbing`), a visual grip handle (`⠿`), strict viewport boundary clamping to keep dialogs fully visible, and automatic position reset upon reopening.
- 🪟 **Enhanced Windows x64 NSIS Installer & CI/CD Builders**: Added GitHub Actions workflows (`.github/workflows/build-windows.yml` and `.github/workflows/release-windows.yml`) for `windows-latest` runner targeting **Windows x64** in both NSIS installer (`.exe`) and standalone portable executable formats with automated SHA-256 integrity hashing. The NSIS installer incorporates architecture inspired by `dail8859/NotepadNext` (`build/installer.nsh`), featuring dual multi-user installation scopes (All Users vs Current User), Windows App Paths shell integration (`Win + R` or `subnetcalc.exe`), and clean uninstallation registry purging.
- 📋 **Enterprise Documentation Headers**: Every single `.ts` and `.tsx` file in `src/` now features standardized enterprise header blocks documenting lead developer contact (`Harry Dertin Sutisna (@alsyundawy)`), maintainer contact (`alsyundawy@gmail.com`), version `1.1.2`, timestamp, filename, architectural lineage, and MIT license.
- 🛡️ **13-Pillar Verification & Zero Circular Dependencies**: Resolved cyclic import paths between engine modules, enforced cognitive simplicity, maintained zero CVEs on `npm audit`, passed 66/66 test suites in `vitest`, and confirmed 0 errors in TypeScript `tsc` and `oxlint`.

### ☁️ 2. Multi-Cloud Subnet Reservation Engine (`src/engine/cloud-profile.ts`)

Subnet allocation requirements vary drastically across hyperscaler cloud providers. SubNetCalc Electron now calculates specific cloud boundary constraints and reservation maps:

```text
IPv4 Subnet 10.0.0.0/24 (256 Total Addresses):
┌────────────────┬──────────────┬─────────────┬──────────────┬────────────────────────────┐
│ Cloud Provider │ Usable Hosts │ Reserved IP │ Allowed CIDR │ Reserved Roles Breakdown   │
├────────────────┼──────────────┼─────────────┼──────────────┼────────────────────────────┤
│ Standard RFC   │ 254 (99.2%)  │ 2 IPs       │ /0 - /32     │ .0 Network, .255 Broadcast │
│ AWS VPC        │ 251 (98.0%)  │ 5 IPs       │ /16 - /28    │ .0 Net, .1 Router, .2 DNS, │
│                │              │             │              │ .3 Future, .255 Broadcast  │
│ Azure VNet     │ 251 (98.0%)  │ 5 IPs       │ /8 - /29     │ .0 Net, .1 GW, .2/.3 DNS,  │
│                │              │             │              │ .255 Broadcast             │
│ Google Cloud   │ 252 (98.4%)  │ 4 IPs       │ /8 - /29     │ .0 Net, .1 GW, .254 Res,   │
│                │              │             │              │ .255 Broadcast             │
│ Oracle OCI     │ 253 (98.8%)  │ 3 IPs       │ /16 - /30    │ .0 Net, .1 GW, .255 Bcast  │
└────────────────┴──────────────┴─────────────┴──────────────┴────────────────────────────┘
```

#### Detailed Cloud Breakdown

1. **AWS VPC**: Enforces AWS VPC boundaries (minimum /28). Reserves 5 addresses per subnet:
   - Network address (`x.x.x.0`)
   - Amazon VPC Router (`x.x.x.1`)
   - Amazon-provided DNS server (`x.x.x.2`)
   - AWS reserved for future use (`x.x.x.3`)
   - Network broadcast address (`x.x.x.255`)
2. **Azure VNet**: Enforces Azure boundaries (minimum /29). Reserves 5 addresses per subnet:
   - Network address (`x.x.x.0`)
   - Default Gateway (`x.x.x.1`)
   - Azure DNS mapping IPs (`x.x.x.2` and `x.x.x.3`)
   - Network broadcast address (`x.x.x.255`)
3. **Google Cloud (GCP)**: Enforces GCP VPC subnet boundaries (minimum /29). Reserves 4 addresses:
   - Network address (`x.x.x.0`)
   - Default Gateway (`x.x.x.1`)
   - Second-to-last address (Reserved by GCP for future routing)
   - Broadcast address (`x.x.x.255`)
4. **Oracle Cloud Infrastructure (OCI)**: Enforces OCI boundaries (minimum /30). Reserves 3 addresses:
   - Network address (`x.x.x.0`)
   - Default Gateway (`x.x.x.1`)
   - Broadcast address (`x.x.x.255`)

### 🪟 3. Draggable Floating About Modal (`src/renderer/components/AboutModal.tsx`)

- **Interactive Pointer & Touch Dragging**: Users can click or touch and drag the modal header or grip handle (`⠿ Drag window`) to reposition the dialog freely across the screen.
- **Viewport Boundary Clamping**: Math guards constrain coordinates so the modal never slides out of the visible viewport (`Math.max(20, Math.min(x, window.innerWidth - width - 20))`).
- **Tactile Visual Feedback**: Cursor updates dynamically to `grab` and `grabbing`, accompanied by active border glow and elevation styling.
- **Automatic State Reset**: Closing and reopening the modal returns it seamlessly to its default centered position.

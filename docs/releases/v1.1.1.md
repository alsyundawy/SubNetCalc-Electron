## 🌟 Executive Summary

**SubNetCalc Electron v1.1.1** delivers an official suite rebranding and major visual rebase inspired by Harry Dertin Sutisna Alsyundawy's [SubnetCalc-MacOS](https://github.com/alsyundawy/SubnetCalc-MacOS) (`ThemeManager.swift`), while preserving 100% of the deterministic pure TypeScript calculation algorithms:

- 🎨 **14-Palette Multi-Theme Engine**: Replaces the binary light/dark toggle with 14 curated developer palettes (Catppuccin Mocha, Macchiato, Frappé, Latte; Dracula; Gruvbox Dark, Light; Solarized Dark, Light; Tomorrow Night Blue, Night, Eighties, Bright, Day) with instant CSS token injection and `localStorage` persistence.
- 🏷️ **Live RFC IP Classification Badges**: Real-time address classification pill badges supporting RFC 1918 Private, Public Internet, CGNAT RFC 6598, Loopback, Link-Local, Documentation RFC 5737, Multicast, Reserved RFC 1112, ULA RFC 4193, and GUA RFC 4291.
- ☁️ **Cloud Architecture Profiles**: Instant presets for AWS VPC, GCP Subnets, Azure VNets, Docker Bridge, Kubernetes Pod Networks, Tailscale CGNAT, Point-to-Point RFC 3021, and IPv6 ULA/GUA.
- 🍏 **Modernized About Modal**: Redesigned macOS card layout with frosted glassmorphism backdrop (`backdrop-filter: blur(20px)`), 4-pillar technical architecture grid, author and sponsorship cards, upstream heritage attribution, RFC compliance matrix, and keyboard shortcut hints.
- 🐛 **Prefix /0 Bitwise Truncation Fix**: Resolved edge-case bug in `flsm.ts` and `vlsm.ts` where `(2 ** 32) >>> 0` wrapped to `0` due to JavaScript 32-bit unsigned bitwise coercion. Total capacity of 4,294,967,296 hosts is now handled accurately.
- 🛡️ **Zero Cognitive Complexity**: Refactored calculation and classifier functions to cognitive complexity &le; 5.
- ♿ **WCAG AAA Compliance**: High-contrast tokens across all 14 themes and donation buttons exceeding WCAG AAA contrast ratio (&gt;7:1).
- ☁️ **Automated Runner Compilation**: Natively compiled directly on GitHub Actions macOS cloud runners (`macos-latest` Apple Silicon ARM64 and `macos-15-intel` Intel x64) with consolidated SHA-256 integrity verification.

### 🔢 2. Advanced Subnetting Engine Suite (`@engine`)

- **FLSM Calculator (`src/engine/flsm.ts`)**:
  - Computes borrowed bits, allocated prefix, subnets generated, network addresses, broadcast addresses, and usable host ranges.
  - Interactive range controls supporting up to 512 subnets per allocation pass.
  - Fixed `/0` subnet size arithmetic without 32-bit bitwise overflow.
- **VLSM Calculator (`src/engine/vlsm.ts`)**:
  - Dynamically sorts subnet requirements descending by host demand to maximize allocation efficiency.
  - Precise block alignment and boundary verification with automatic capacity overflow detection.
  - Fixed `/0` parent capacity and boundary overflow evaluation.
- **CIDR Route Summarizer (`src/engine/cidr.ts`)**:
  - Aggregates multiple IPv4 routes into minimal supernets via leading bit-pattern matching.
  - Automatically sorts blocks and checks contiguity for gaps or overlapping subnets.
- **RFC 4180 CSV Export (`src/engine/export.ts`)**:
  - Export subnet plans to CSV directly from FLSM and VLSM views.
  - Strict quotation escaping and sanitization against spreadsheet formula injection triggers (`=`, `+`, `-`, `@`).
